# MovieSnack

Веб-приложение для случайного подбора еды под фильм по его жанру.
Пользователь выбирает жанр — приложение предлагает подходящий перекус
(мультфильмы → мармелад, хоррор → стейк) и делает киновечера вкуснее.

## Название проекта

**MovieSnack** — подбор еды под фильм по жанру.

---

## Описание проекта

Веб-приложение, которое помогает выбрать еду под просмотр фильма.
На основе выбранного жанра (или названия фильма) система случайным
образом предлагает блюдо или перекус, подходящий настроению картины.
Приложение хранит базу пар «жанр — еда», ведёт историю подборов
и позволяет расширять каталог.

---

## Функциональные требования

### Пользователь (гость)

- Просмотр списка жанров
- Случайный подбор еды по жанру
- Кнопка «Ещё вариант» без перезагрузки страницы

### Пользователь (авторизованный)

- Регистрация и авторизация
- Поиск фильма по названию с определением жанра
- Добавление еды в «Избранное»
- Просмотр истории подборов
- Оценка предложенных пар

### Администратор

- Управление пользователями
- Управление жанрами и блюдами
- Управление связями «жанр — еда»
- Просмотр статистики
